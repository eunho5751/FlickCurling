# 튜토리얼

## 언제 나오나

- 앱을 켜면 Boot가 확인한다(`TutorialProgress.NeededAsync`).
  - 이 기기에 완료 기억(PlayerPrefs `tutorial.done`)이 있으면 바로 메인 메뉴.
  - 없으면 로그인을 기다렸다가(네트워크 팝업이 그동안 뜰 수 있음) Cloud Save 플레이어 기본 데이터의 `tutorialDone`을 읽는다. 있으면 기기에도 기억하고 메인 메뉴.
  - 둘 다 없으면 게임 씬을 튜토리얼로 연다(`MatchLaunch.SetTutorial`). 읽기에 실패해도 보여 준다(건너뛸 수 있어서).
- 완료나 건너뛰기를 하면 기기에 기억하고 Cloud Save에 `tutorialDone = true`를 쓴다(`TutorialProgress.MarkDone`). 쓰기에 실패하면 다음 실행 때 다시 쓴다. 조작해도 이득이 없어서 서버 함수 없이 기기가 직접 쓴다.
- 이미 게임해 본 계정도 처음 한 번은 본다. 새 플레이어의 닉네임 팝업은 튜토리얼 뒤 메인 메뉴에서 뜬다.

## 구조

- 게임 씬을 그대로 쓴다. 시트, 물리, 카메라, HUD, 카드, 입력, AI가 다 거기 있어서, 튜토리얼 씬을 따로 만들면 같은 것이 두 벌이 된다.
- `GameController.Tutorial.cs`: 튜토리얼이 쓰는 연결 지점만 둔다.
  - 정해진 샷 쏘기: AI 샷처럼 보이고, 멈추면 다음 차례 대신 튜토리얼에 알린다.
  - 알 놓기, 엔드 측정: 끝나면 엔드 카드 대신 튜토리얼에 알린다.
  - 조준·세기 직접 바꾸기, 조작 영역의 화면 위치
  - 마지막 실전 1엔드
- 튜토리얼 동안 달라지는 것: 샷 타이머 없음, 선후공 정하기 없음, 연장 없음. 실전 전까지는 플레이어 입력을 막는다. 설정 팝업의 "메인 메뉴로 이동"이 "튜토리얼 건너뛰기"로 바뀌고, 누르면 확인 카드가 뜬다.
- `TutorialDirector`: 단계 진행. HUD 안의 레이어(토스트, 카드, 설정 톱니바퀴 아래)에 설명 상자, 금색 테두리, 손가락, 화살표를 그린다. 설명 상자는 반투명으로 토스트 자리(최소 라인 바로 위)에 나오고, 토스트가 떠 있으면 그 위로 올라간다. 튜토리얼에서 내 이름은 "플레이어"로 고정한다. 손가락과 화살표 그림은 Codex로 만들었다(`Resources/Tutorial`).

## 단계

연출이 끝나면 "탭하여 계속"이 깜빡이고, 탭하면 다음으로 넘어간다.

1. 인사
2. 게임 소개
3. 규칙
   - 번갈아 던지기: 흑(나)과 백(AI)이 한 알씩 자동으로 던진다(중앙, 하우스 안).
   - 무효(설명 한 번, 시연 두 번): 약한 샷이 최소 라인 앞에서 멈추고 사라지고, 이어서 센 샷이 아웃 라인을 넘어 사라진다.
   - 점수: 흑 알 하나를 더 놓고 엔드를 측정한다(흑 2점).
4. 조작법. 해당 영역에 금색 테두리(딤 없음). 알 아래 두 영역은 알 중앙에서 나뉘고, 테두리 선은 발사할 알(세기 링 포함)을 지나는 부분만 잘라서 알과 겹치지 않는다. 화면 크기에 맞춰 매 프레임 계산하고, 화면 가장자리에서 조금 안쪽에 그린다. 16:9, 19.5:9, 20:9, 4:3(태블릿)에서 확인했다.
   - 왼쪽(최소 라인 아래, 알 왼쪽): 손가락과 좌우 화살표가 좌우로 움직이고 조준선이 따라 돈다.
   - 오른쪽(알 오른쪽): 손가락과 상하 화살표가 아래로 당기고 세기 게이지가 찬다(두 번).
   - 최소 라인 위: 손가락이 한 곳을 누르면 조준이 그곳을 향하고, 끌면 조준이 따라간다.
5. 실전: AI(쉬움)와 1엔드. 플레이어가 마지막 알을 갖고, AI가 보너스 가드와 함께 먼저 던진다.
6. 완료 카드(내 결과와 점수) → "시작하기" → 완료 기록 → 메인 메뉴

시연 샷의 세기는 직선(각도 0)으로 시뮬레이션해서 정했다. 0.70은 중앙(y≈172), 0.36은 최소 라인 앞(y≈56), 0.86은 아웃(y≈228)이다.

## 테스트 (에디터)

- 튜토리얼 여부는 Boot 씬에서 정한다. 에디터에서 메인 메뉴 씬을 열어 둔 채 Play하면 Boot를 거치지 않아 튜토리얼이 나오지 않는다. **FlickCurling > Tutorial > Play From Boot**로 Boot부터 시작한다.
- **FlickCurling > Tutorial > Reset Tutorial**: 이 기기의 완료 기억을 지우고, 로그인한 플레이어의 Cloud Save `tutorialDone`도 지운다(Play 중이면 바로, 아니면 다음 시작 때 확인하면서).
